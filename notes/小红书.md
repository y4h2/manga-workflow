标题

🔥 AI漫剧角色总是换脸？这个方法让一致性拉满！

正文

用AI生成漫剧时最头疼的问题：
每个镜头的角色都像换了张脸！😭

今天分享一个「三层金字塔」方案
彻底解决角色一致性问题👇

━━━━━━━━━━━━━━

📐 第一层：基础三视图

先让AI生成角色的「身份证照」：
正面｜侧面｜背面 三个角度
这是角色的「基准设计」
后续所有生成都以它为参考

━━━━━━━━━━━━━━

📐 第二层：阶段参考图

故事发展中角色会有变化
（比如衣服破了、皮肤晒黑了）

基于三视图生成各阶段的变体：
✓ 保持核心特征（脸型、身材、比例）
✓ 只改变该阶段的元素（服装状态、肤色）

关键：让AI知道「哪些必须保持，哪些可以变」

━━━━━━━━━━━━━━

📐 第三层：镜头图片

生成具体镜头时用「链式参考」：

同一场景内 → 每帧参考上一帧
像接力棒一样传递一致性

场景切换时 → 背景图 + 角色阶段参考图
自动重置，灵活又稳定

━━━━━━━━━━━━━━

🎨 人物与背景分离

背景和角色是分开生成的！

先生成每个场景的纯背景图
再把角色「放进」背景里

好处：
✓ 背景稳定，不会每帧都变
✓ 同一场景的镜头风格统一
✓ 故事连贯性大幅提升

━━━━━━━━━━━━━━

💡 核心技术点

用 Gemini API 的图片参考功能
同时传入「参考图 + 提示词」

Prompt 里要明确约束：

你必须保持：脸型、身材、比例
你可以改变：服装状态、表情、姿势

这比让AI「记住角色」聪明多了
是用结构化的约束框架来控制生成

━━━━━━━━━━━━━━

🛠️ 工具说明

整套工作流是用 Claude Code Skill 搓出来的
一个命令就能跑完全流程：
故事大纲 → 分镜 → 三视图 → 阶段图 → 背景 → 镜头

AI写代码 + AI生图 = 全自动漫剧生产线 🏭

━━━━━━━━━━━━━━

🎬 最终效果

❌ 无参考时：每帧换脸，像在看变脸表演
✅ 三层参考后：全程同一个角色，稳如老狗

⚠️ 视频用幻灯片展示是因为 Veo3 每天只有10条配额
配额充足的话，每张图都可以用图生视频
效果会更丝滑～
